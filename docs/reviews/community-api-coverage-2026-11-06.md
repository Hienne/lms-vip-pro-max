Coverage: **43/138 = 31.16%**. The unused set is 2 declared-only plus 93 not declared.

The user's 135-endpoint baseline differs from current source: the controller inventory and existing
`corebanking-academy/docs/api/COMMUNITY.md` both report 138 active endpoints. If 135 refers to
C01–C138 excluding suspended C126–C128, FE consumes **40/135 = 29.63%** of that baseline;
C139–C141 are three additional active endpoints, all consumed by the moderation UI. This is a
conditional reconciliation of the older number, not a claim about its original provenance.

## Counting method and limitations

- One endpoint is one unique HTTP method plus normalized path; path variable names do not change identity. Repeated calls count once. HEAD is counted separately.
- Backend: inspect Java controller mappings and actual, uncommented `@RestController` annotations. All 141 mappings reconcile with documented C identifiers. Only CommunityAiController lacks a registered controller annotation.
- Frontend: inspect TypeScript syntax trees for all Community `defineEndpoint` declarations and imports/references in non-test application sources, including aliases such as `communityMediaEndpoints as media`. Exclude specs, testing helpers, mock handlers and declaration-only references.
- Manually verify dynamic dispatch: `ContentAuthoring.CREATE[kind]` reaches `client.call` for question/article/lesson; ArticlesStore chooses article or lesson list; editor/ask commands and thumbnail reads are reachable from registered screens. Navigation-only requirements in screens.ts are not counted as request execution.
- “Used” means an implemented FE application consumer, **not** evidence of a successful production request or usage telemetry. No production calls were made for this audit. Endpoint coverage does not prove all role/scope combinations or business actions have complete UI.
- New thumbnail APIs are counted from the current working tree, including uncommitted changes.
- A header notification bell or general notifications page does not establish Community notifications integration: BellPanel reads Learning reminders/instructor feedback; the Community notifications/digest endpoints remain unused.
- Knowledge Hub, the global AI assistant and learning analytics are separate modules; their APIs are not substituted for Community Wiki/Radar/AI/analytics.
