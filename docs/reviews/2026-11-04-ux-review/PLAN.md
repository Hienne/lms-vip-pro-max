## 1. Scope

**In:** every review item the app (`lms-vip-pro-max`), the backend (`~/my-projects/corebanking-academy`) or its
nginx config can fix. Where a fix needs the backend, the backend change is part of the same package.

**Out, by request:**

- AI assistant: P5 / B14, the "Tài liệu 0" half of U12, the `/knowledge/documents?…` polling half of S2.
- Community: B4 (moderation 403), the "0 câu hỏi" half of U12, the community "Đặt câu hỏi" form in U19 and row 22
  of the review table.

**Out, not code:** U8 (test data on production) and the data the review itself created: the data owner cleans them
(list in the README).

**Out, later (D7):** S1. The access token moves to an HttpOnly cookie under a separate spec.

## 2. Backend baseline

`corebanking-academy` `main` is behind: lesson feedback, certificates, the course wizard, final exam and publish
targets live on stacked feature branches, the latest being `feat/course-publish-targets` (it contains the others).
Production answers lesson comments and ratings, so it runs one of those branches.

- Every backend change below starts from the branch production is built from (assumed
  `feat/course-publish-targets`; confirm as D0) and ships as its own branch and PR in `corebanking-academy`.
- Schema changes ship as a `docs/sql/upgrade/` script, its rollback, and the `psql` command (as the earlier
  modules did). Javadoc and comments in Vietnamese (`DEVELOPMENT_GUIDELINES.md`). `docs/api/*.md` updated.
- The app side re-captures fixtures from the local backend (`contracts-and-mocks.md`) and updates the mock API.

## 6. Suggested order

1. Wave 0: `pdf-worker-mime`, `unfinished-screens` and `question-bank-gate`. Small, and they remove the most
   visible breakage.
2. `course-editor-guards`, `report-filters` and `progress-reports`. All three are app only and touch different
   features, so they can run in parallel.
3. `question-bank`: capability map first, then the BE change, then the app.
4. Wave 2: `deadline-reminders` and `users-admin`, which have small BE changes. Then `header-search` and
   `admin-table-mobile`. Then `assignments-ux` (L, capability map first).
5. Wave 3, two packages at a time. `streak-rule` is BE only and can go at any point.

A package is done when:

- `npm run check` is green (plus the backend `mvn verify` when BE changed);
- angular.md §14 and the visual-design.md checklist pass at 1280 and 375px, light and dark;
- the review item, re-tested the way the README reproduced it, now works.
